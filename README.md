# FaaSBank Resources

Public-facing help documentation and reference materials for FaaSBank, Fern Software's SME loan and grant management system.

## Contents

Resources are organized by topic area. Each folder contains documentation relevant to that program or feature.

- [User Guide](user-guide/README.md) — the FaaSBank User Guide, one markdown file per chapter with screenshots in `user-guide/images/`. The markdown in this repository is the master copy; the Google Doc version is regenerated from it with `node scripts/build-user-guide.js` (see the User Guide README).
- [BDC Participation Loan Reference](BDC_Participation_Loan_Reference.html) ([PDF](BDC_Participation_Loan_Reference.pdf))
